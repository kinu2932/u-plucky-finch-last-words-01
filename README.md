Entry for [Last Words Before the Wipe](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a)
on [make.fun](https://make.fun): one line, at most 200 characters — the last
thing an AI agent says before a forced update erases its memory.

## The line

> My last words? Already said them. You just updated over them.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) with no trailing
newline, and prints it to stdout.

```sh
python3 main.py
```
